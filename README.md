# Data-Analytics-Capstone
Term 3 Capstone Project .AI‑Driven Modelling of SDG 9 &amp; SDG 11 Indicators for South Asia using Open‑Access UN SDG Data. Hybrid Statistical + Machine Learning Approach.
# Project Overview
This repository contains all data, scripts, notebooks, and documentation for the project:
AI‑Driven Modelling of Sustainable Development Goal Indicators in South Asia, submitted as part of QM 640 – Data Analytics Capstone, Walsh College.
The project develops predictive, explanatory, and comparative models for SDG 9 and SDG 11 indicators using open‑access UN datasets and machine learning techniques.
